
# Examen 5 - eLEARNING

## Descripcion

Pagina web educativa desarrollada con HTML5, CSS3,
Bootstrap 5 y JavaScript.

El proyecto reproduce el diseño de referencia
del examen de Programacion IV.

## Autores

- Stiven Hernandez
- Kevinn Cuervo

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Google Fonts

## Caracteristicas

- Barra de navegacion responsive
- Metodologia BEM
- Imagen principal con capa oscura
- Carrusel interactivo
- Botones de navegacion
- Boton para volver al inicio
- Secciones informativas
- Formulario de demostracion
- Adaptacion para PC, tablet y celular

## Metodologia BEM

Ejemplos utilizados:

- Bloque: hero
- Elemento: hero__title
- Modificador: hero__button--primary

## Estructura

Examen 5/
- index.html
- styles.css
- script.js
- README.md
- Imagen/
  - logo.svg
  - graduacion.jpg

## Ejecucion

Abrir el archivo index.html en un navegador.

Se requiere conexion a internet para cargar
Bootstrap y Google Fonts desde sus CDN.

## Publicacion

El proyecto se publica mediante GitHub y Netlify.
